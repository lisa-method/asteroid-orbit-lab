Можно ли предсказать движение астероида на год вперёд, не рассчитывая все
возмущения каждый раз? В этом pet project физические модели разной сложности
соревнуются за точность и время. Селектор выбирает одну модель **до начала
прогноза**, а затем она строит всю будущую траекторию из начального состояния.

![2001 AV43: прогноз и JPL Horizons постепенно рисуют годовую траекторию](docs/figures/trajectory_showcase/2001_AV43__overview.gif)

**Один астероид, две траектории.** Оранжевая — прогноз, бирюзовая — JPL Horizons.
Маркеры движутся синхронно и оставляют растущий след. В этом примере максимум
расхождения за год — **33,947 м**; обзор сохраняет настоящий пространственный
масштаб. Horizons — вычисленная номинальная эфемерида, используемая как эталон.

## Результат на 100 новых телах

Метод зафиксирован до загрузки новых эталонных траекторий. Проверены **100 ранее
не использованных тел** в девяти группах: сближения с Землёй, Венерой, Марсом
и Юпитером, поясные контроли, негравитационные параметры и малые перигелии.
Пять горизонтов — **7, 30, 90, 180 и 365 суток**.

| Метод | Окна в пределах 1 км | Максимальная ошибка | Время¹ |
| :--- | ---: | ---: | ---: |
| **Физическое правило v4** | **500 / 500** | 806,438 м | **413,839 с** |
| Гибрид v4 с CART | 500 / 500 | 522,314 м | 418,163 с |
| Постоянный полный кандидат | 500 / 500 | 153,166 м | 592,082 с |
| Прежний CART v3 | 499 / 500 | 1 265,050 м | 421,726 с |

**Физическое правило сокращает время на 30,10% относительно полного кандидата.**
ML-поправка уменьшает максимальную ошибку, но в этом сравнении не добавляет
успешных окон и не ускоряет расчёт относительно правила.

¹ Время измерено отдельно на **заранее выбранных 24 телах**: сумма 120 медиан
трёх прямых повторов. Расчёт признаков, выбор и rollout включены; общая загрузка
эфемерид и оценка результата исключены. Все методы проходят 120/120 этих окон.
500 вложенных окон не являются 500 независимыми объектами; ошибка проверяется
на сохранённой временной сетке относительно Horizons.

## Как устроен прогноз

```text
Начальное положение и скорость + доступные эфемериды планет
                           + горизонт и допуск
                                    │
                                    ▼
                  Предварительный дешёвый прогноз
                 и физические признаки возмущений
                                    │
                                    ▼
                  Физическое правило / CART-поправка
                                    │
                                    ▼
                  Один набор сил на всю траекторию
                                    │
                                    ▼
               Положение, скорость, ближайшее сближение
```

Линейка начинается с двухтельной модели Солнце–астероид. Следующие кандидаты
учитывают планеты и Луну, несферичность поля Земли и доступные негравитационные
параметры, затем солнечную релятивистскую поправку и 16 массивных астероидов.
Постоянная скорость и восстановленный центральный закон сохранены как первые baselines.

**Роль ML:** небольшие CART-регрессоры предсказывают поправку к физической оценке
ошибки кандидата. Обучение и calibration разделены целыми телами: 42 и 24.
Номер астероида и его будущие эталонные состояния не входят в признаки.
Модель оценивается по собственной развёрнутой траектории и полной стоимости.

## Когда ошибка становится исследованием

### Земля не совсем шар

У одного из изученных объектов годовое расхождение составляло около 13,45 км.
Добавление Earth J2 — поправки на несферичность гравитационного поля Земли —
уменьшило его до 29,85 м. Это адресная физическая проверка на development-объекте;
перенос общего метода оценивался позже на новых телах.

![Как Earth J2 изменяет прогноз 153814: физическая диагностика](docs/figures/physics_diagnostics/153814-earthj2.svg)

### У Апофиса осталась загадка

Сильное сближение усиливает малые различия в начальном состоянии и модели.
Проверки численной схемы, эфемерид и слабых сил устранили часть проблем,
но годовой остаток специальной модели Апофиса всё ещё **2,552 км**.
Причина всего остатка не установлена.

![Апофис: предварительная реконструкция PDS Model B в трёх проекциях](docs/figures/physics_diagnostics/apophis-pds-shape.svg)

*Реальная предварительная PDS-реконструкция формы, Brozović et al.,
[DOI: 10.26033/ydyq-5756](https://doi.org/10.26033/ydyq-5756).
Форма и её фиксированные ориентации изучались отдельно; это не прогноз вращения при пролёте.*

[Три истории: гипотеза → проверка → вывод](docs/PHYSICS_STORIES.md)

## Где заканчивается результат

- При строгом допуске **100 м** оба v4 проходят **498/500** окон. Один отказ —
  неудачный fallback при наличии достаточного кандидата; в другом недостаточны все кандидаты.
- Предупреждения пока не откалиброваны: OOD не равнозначен ошибке прогноза.
- Апофис не входит в 100 новых тел. Его годовой допуск 1 км остаётся невыполненным;
  сильные встречи такого уровня требуют отдельной проверки.
- Это условное распространение орбиты относительно Horizons. Оценка вероятности
  столкновения и определение реальной орбиты из телескопических наблюдений — другие задачи.

## Попробовать локально

Требуются **uv** и Python **3.14.7**. Основной Python-код использует стандартную
библиотеку. Компактный пример включён в репозиторий и работает без скачивания данных:

```sh
git clone https://github.com/lisa-method/asteroid-orbit-lab.git
cd asteroid-orbit-lab
uv run --no-project --python 3.14.7 python examples/orbit_demo.py
```

Пример интегрирует синтетическую круговую орбиту и сравнивает её с точным
аналитическим решением: положение, энергию и угловой момент. Он показывает
работу численного кода; это **не запуск v4 и не повторение benchmark 100 тел**.

```sh
uv run --no-project --python 3.14.7 python -B scripts/run_portable_tests.py
uv run --no-project --python 3.14.7 python scripts/check_publication.py
```

[Что именно воспроизводится](examples/README.md) ·
[Полный научный запуск и данные](docs/REPRODUCIBILITY.md)

В чистой копии выполняются 320 тестов; пять проверок оригинальных raw-ответов
явно пропускаются до подключения полного архива. На локальном архиве проходят все 325.
