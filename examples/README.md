# Самодостаточный численный пример

```sh
uv run --no-project --python 3.14.7 python examples/orbit_demo.py
```

Начальное состояние задаёт синтетическую круговую орбиту радиуса 1 AU.
Пример вызывает неизменённые `State`, `propagate` и `two_body_acceleration`
из научного кода и сравнивает результат RK4 с точным аналитическим решением.

В выводе — ошибка положения на шести датах и относительное изменение энергии.
Также проверяется сохранение углового момента. Используются только стандартная
библиотека и фиксированные параметры примера; загрузки данных нет.

Это демонстрация численного ядра, **не реальный астероид, не запуск v4 и
не повторение результатов confirmation100**. Допуски примера служат smoke-проверкой
и не являются научными критериями основного эксперимента.

Обученные модели и полные данные не включены в Git. Для нового forecast нужны
начальное состояние, эфемериды, сохранённые модели и доступные NG.
См. [научный API](../docs/SELECTOR_V4_USAGE.md) и
[уровни воспроизведения](../docs/REPRODUCIBILITY.md).
