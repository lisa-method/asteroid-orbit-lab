# About the research snapshot

This repository preserves a completed, versioned experiment in asteroid
trajectory propagation and physical model selection.

The scientific sources, configurations, tests and contracts used for the
completed v3/v4/confirmation100 experiments are frozen. Do not silently edit
them, refit a completed model, or rerun a completed matrix/timing phase.
New scientific settings belong in a separate version and need a new evaluation
protocol. The previously inspected 100 bodies are no longer a pristine test set.

Presentation documents, small examples and publication checks can be improved
without changing historical scientific results. Keep raw data, full traces,
trained models, environments and credentials outside Git.

Start with [the code map](docs/START_HERE.md) and
[the reproducibility boundary](docs/REPRODUCIBILITY.md).
