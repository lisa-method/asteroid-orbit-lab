# Апофис: релятивистская модель и движение начала координат

Дата: 2026-09-09. Post-hoc диагностика уже изученного пролёта 2029 года.
Два последовательных эксперимента: [PPN/EIH](APOPHIS_EIH_CONTRACT.md)
и [прямое барицентрическое движение](APOPHIS_EIH_BARYCENTRIC_CONTRACT.md).
Вторая гипотеза выбрана после просмотра результатов первой серии;
её собственный контракт заморожен до расчётов. Коэффициенты не подгонялись.
Это не новая validation селектора и не оценка точности относительно наблюдений.

## Что изменено и зачем

Прежняя релятивистская поправка — изолированный солнечный Schwarzschild.
Реализована общая 1PN/PPN формула при beta=gamma=1, с потенциалами других
масс, скоростями в барицентрической системе и ускорениями источников.
Солнце, восемь планет, Луна и Pluto system участвуют в PPN; SB16 действуют
ньютоновски. Это первый порядок по 1/c², а не решение полной ОТО.

[Holman et al. (2023), §III.2 и уравнение 2](https://arxiv.org/html/2303.16246v1)
различают полную PPN модель JPL small-body integrator и вариант Horizons
с внешней суммой только по Солнцу. Такой вариант сохраняет планеты во
внутренних потенциалах и отличается от изолированного Schwarzschild.
Поэтому проверены обе внешние суммы, а не только максимально полный набор.
Внутренние ускорения источников рассчитаны ньютоновски по главным телам;
авторы допускают этот подход внутри 1PN членов. Точное устройство
сохранённого решения Horizons JPL#220 этим источником не удостоверено.

Во всех новых ветвях сохранены nominal A1/A2/A3, Earth J2 с фиксированной
J2000 z-осью и остальные прежние силы. Earth J3/J4 выключены: все восемь
сохранённых заголовков teacher объявляют Earth J2 only. Solar J2 включён
отдельным фактором с прежними DE441 коэффициентом, радиусом и осью.
Pluto добавлен отдельным ньютоновским контролем до изменения PPN.

## Одинаковые входы и основной эталон

Старт 2029-01-01 TDB, горизонт 365 дней. Начальное шестимерное состояние
взято из annual-hourly запроса; основная ошибка измерена по annual-daily
таблице, на 366 суточных узлах. Всего сохранены 797 диагностических узлов
и сравнения с восемью reference таблицами по отдельности. Максимум на
суточной сетке не является доказанным максимумом непрерывной траектории.
Старый long-query teacher с другим initial не подменяет основной эталон.

Новые данные — только экзогенные часовые ряды Sun–SSB и Pluto–Sun:
по 8809 состояний с 2028-12-31 по 2030-01-02, ICRF/FRAME, AU-D, TDB,
геометрические векторы без light-time corrections. Новые будущие состояния
астероида не запрашивались. Forecast callback получает прогнозируемый state
и планетные эфемериды; reference состояния в него не передаются.

## Первая серия: гелиоцентрическая форма уравнений

Здесь из ускорения астероида вычитаются модельные ньютоновское и PPN
ускорения Солнца. Для PPN ускорения самого Солнца сохранена полная внешняя
сумма по главным источникам. Это приближение к ускорению начала координат,
заданного внешней DE441 эфемеридой, а не проверенное равенство её второй
производной и нашего конечного набора сил.

18 records: шесть вариантов × DP extreme / DP ultra / RK4 fine.
Три baseline traces точно переиспользованы, 15 propagations выполнены впервые.

| Вариант | DP extreme, km | DP ultra, km | RK4 fine, km |
|---|---:|---:|---:|
| Fixed Earth pole + прежний Schwarzschild | 7.292220 | 7.292059 | 7.290829 |
| То же + Pluto | 6.951371 | 6.951236 | 6.950010 |
| PPN, внешняя сумма Sun-only | 3.171157 | 3.171305 | 3.172521 |
| PPN, внешняя сумма all-major | 16.723796 | 16.723952 | 16.725198 |
| PPN Sun-only + Solar J2 | 2.299771 | 2.299632 | 2.298487 |
| PPN all-major + Solar J2 | 11.597409 | 11.597544 | 11.598782 |

Pluto даёт **343.110 m векторного сдвига** к концу года; разность этого
эффекта между алгоритмами всего 3.18 mm. Его влияние для прежних WN5/TU7
было субметровым, но этот вывод нельзя переносить на чувствительный пролёт
Апофиса. Pluto здесь не является объяснением всего остатка.

PPN Sun-only сдвигает траекторию относительно Pluto-контроля на 9.956 km,
all-major — на 23.607 km. Это нормы разностей траекторий, не уменьшение
скалярной ошибки. Соответствующие векторы эффектов между DP и RK4
согласуются до 33.2 и 15.0 mm.

DP extreme/ultra отличаются на 0.137–0.164 m. Абсолютные DP ultra/RK4
траектории отличаются на 1.234–1.267 m: прежний критерий ≤1 m не пройден
ни одной ветвью. Километровые эффекты подтверждены обоими алгоритмами,
но эта проверка не доказывает метровую абсолютную точность.

До близкого пролёта PPN Sun-only без Solar J2 уменьшает ошибку на 102-й
день с 2.539 до 0.266 m относительно Pluto-контроля. Solar J2 повышает
её до 1.346 m, хотя годовая норма становится меньше. Поэтому самый низкий
годовой остаток 2.300 km сам по себе не доказывает правильность всего
сочетания поправок: возможна компенсация других отличий.

## Вторая серия: прямое барицентрическое движение

Чтобы не приближать ускорение начала координат, интегрируется движение
в инерциальной системе с равномерно движущимся началом:

```
q = r_b − rSun_b(0) − t vSun_b(0)       q' = w
w = v_b − vSun_b(0)                    w' = a_b
```

Начальные q,w в точности совпадают с исходными гелиоцентрическими r,v.
Для сил и выдачи результата восстанавливаются:

```
ds = [rSun_b(t) − rSun_b(0)] − t vSun_b(0)
dvs = vSun_b(t) − vSun_b(0)
r_h = q − ds                         v_h = w − dvs
```

Ньютоновские, PPN и Earth J2 ускорения здесь прямые, без вычитания
модельного ускорения Солнца. PPN использует истинные барицентрические
скорости `v_b = w + vSun_b(0)`, NG — гелиоцентрические r_h,v_h.
Кинематическое преобразование не предполагает Galilean invariance PPN.
Солнечная эфемерида не дифференцируется численно. Шаг RK4 выбирается
по гелиоцентрическому прогнозируемому state для правильной геометрии встречи.
Нативные и преобразованные states/endpoints сохраняются раздельно.

Все четыре PPN ветви повторены при тех же трёх настройках — 12 новых
propagations, без новых данных и без изменения предыдущей матрицы.

| Вариант | Гелиоцентрический DP ultra, km | Прямой барицентрический DP ultra, km | Прямой барицентрический RK4, km |
|---|---:|---:|---:|
| PPN Sun-only | 3.171305 | 2.351305 | 2.352437 |
| PPN all-major | 16.723952 | 15.882539 | 15.883775 |
| PPN Sun-only + Solar J2 | 2.299632 | 3.062309 | 3.061137 |
| PPN all-major + Solar J2 | 11.597544 | 10.755720 | 10.756968 |

Векторные сдвиги между системами уравнений составляют 841.755–841.824 m
для DP ultra; RK4 даёт 841.814–841.824 m. Разница скалярных reference
errors может иметь другой знак и величину, поэтому эти сдвиги рассчитаны
не вычитанием норм ошибок, а сравнением шестимерных прогнозов.
DP extreme/ultra в прямой постановке различаются на 0.148–0.168 m,
DP ultra/RK4 — на 1.207–1.253 m. Все четыре ветви по-прежнему не проходят
заранее заданный межметодный критерий ≤1 m.

В прямой постановке Solar J2 повышает годовую ошибку Sun-only ветви,
тогда как в первой серии понижает. Минимум среди всех записей первой
серии около 2.30 km не превращает её приближённое вычитание ускорения
Солнца в более обоснованную систему отсчёта. Прямая постановка устраняет
это конкретное приближение, но не доказывает совпадение остальных inputs
и сил с JPL. Ни 1 km, ни 100 m не достигнуты в годовом окне.

## Что это означает для программы

Реализованы общие force factories `eih_force_model.py` и
`barycentric_eih.py` с явными режимами PPN и входными эфемеридами.
Идентификатор астероида не выбирает уравнения. ID источников гравитации
используются для состава сил, что отличается от маршрутизации по target ID.
Конфиги с именем Apophis задают воспроизводимый эксперимент на одном событии.
Frozen forecast API, selector и прежние validation scores не заменены.

Для похожих тел нужен общий режим прогноза через сильное гравитационное
рассеяние: предварительная одновременная геометрия встречи, чувствительность
к входным состояниям и малым силам, согласованные координаты/время/константы,
достаточный численный бюджет. Набор сил по текущему контракту выбирается
для всего rollout. Предупреждение о неподтверждённом допуске должно
опираться на forecast-time признаки; будущая reference error допустима
только в оценивателе. Правило такого предупреждения ещё предстоит проверить
на новых событиях, оно не реализовано этим аудитом.

Форма тела остаётся отдельным физическим вопросом. Наши предыдущие
fixed-attitude COM эффекты порядка метров не объяснили километровый
остаток; это не исключает влияние spin/thermal evolution на других
горизонтах. Fitted A2 и тепловую модель одной и той же отдачи нельзя
суммировать как независимые силы. Для бинарной системы сначала нужно
зафиксировать, прогнозируется барицентр или конкретный компонент.

Ближайшая содержательная проверка — независимая реализация сил с одним
согласованным пакетом планетных эфемерид и констант, затем локальная
проверка интерполяции/численной сходимости около встречи. Прямой SPK backend
поможет отделить интерполяцию часовых таблиц от силы; он в этой фазе
не установлен и не проверен. Вариационные уравнения или симметричные
возмущения initial/A2 позволят затем построить общий sensitivity-критерий.
Без наблюдательной covariance это будет чувствительность, а не вероятность
ошибки реального положения. Очередная неподтверждённая слабая сила или ML
closure по одному остатку пока не имеет установленного преимущества.

## Воспроизведение

Python 3.14.7 через uv, standard library. Установок, новых зависимостей,
commit или публикации нет. Матрицы и полные traces локальны и исключены
из Git; компактный отчёт и контракты можно включить в историю физической
диагностики. Данные и исходники предыдущих экспериментов сохранены.

```bash
env UV_CACHE_DIR=/private/tmp/astrophysics-ml-uv-cache UV_OFFLINE=1 UV_PYTHON_DOWNLOADS=never uv run --no-project --python-preference only-system --python 3.14.7 python -B src/verify_apophis_eih.py
env UV_CACHE_DIR=/private/tmp/astrophysics-ml-uv-cache UV_OFFLINE=1 UV_PYTHON_DOWNLOADS=never uv run --no-project --python-preference only-system --python 3.14.7 python -B src/verify_apophis_eih_barycentric.py
```

Генераторы `run_apophis_eih.py` и `run_apophis_eih_barycentric.py`
переиспользуют completed checkpoints без propagation. Параметры и контракты
для обеих серий frozen; изменение требует следующей версии эксперимента.

Проходят **198 unit tests**: общий stationary-Sun PPN предел, известный
двухмассовый 1PN предел, перестановки/вращения/переносы, масштаб 1/c²,
проверки frame conversion и прямой силы при ненулевом времени.
Повторное использование старого Schwarzschild baseline проверено точно.
Тесты формул не являются независимой сверкой сил с закрытым кодом JPL.

Offline проверки пересчитали 115,992 scalar position/velocity errors в
первой серии и 77,328 во второй. Проверены соответственно 609,744 и
406,515 accepted endpoints; во второй серии также все native-to-helio
конверсии из raw солнечного ряда и точное совпадение requested/native
endpoints. Эти многократные сравнения относятся к одному inspected событию.
SHA-256, размеры и Git exclusion всех 140 raw файлов / 15 manifests
проверены; fingerprint включает численные исходники, contracts, configs,
inputs, прежние matrices и фактический Python runtime.

При review усилен offline verifier: проверки metadata/input provenance,
точного native alignment и отдельный флаг DP-setting budget. Первоначальные
verification JSON сохранены в `verification_v1/`; отдельной копии исходника
v1 нет. Один запуск, пересёкшийся с этой редакцией, остановился на защите
immutable mismatch. После завершения редакции финальная проверка повторно
прошла; propagation, matrix и freeze ни разу не менялись.
Resume проверен без интеграции: SHA-256 и timestamps 40 JSON файлов первой
PPN/предыдущей gravity серии и 15 propagation/input JSON второй серии
неизменны. Дополнительно сверены исходные hashes четырёх прежних matrices.
