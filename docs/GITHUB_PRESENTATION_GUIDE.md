# Что сохранить и показать на GitHub

Путеводитель по оформлению pet project, 10 сентября 2026.
Здесь собраны пожелания из обсуждения, ссылки на готовые материалы и
предложение по их размещению. Цель — показать интересный эксперимент:
как мы прогнозировали движение астероидов, разбирались в ошибках через
физику и учились выбирать достаточную модель.

Материалы уже подготовлены локально. Этот файл фиксирует оформление;
создание репозитория, push и публикация в его рамках не выполнялись.

## 2. История поиска ошибки через физику

Эту часть стоит сохранить как самостоятельный рассказ. Для каждого случая
достаточно одной короткой карточки: **ошибка → гипотеза → проверка →
результат → что осталось непонятным**. Подробные расчёты открываются по ссылке.

Материалы для рассказа:

- **Несферичное поле Земли.** У 153814 поправка Earth J2 уменьшила годовое
  расхождение примерно с 13.45 km до 29.85 m. Это адресный разбор уже
  просмотренного тела. [Готовая SVG-панель](figures/physics_diagnostics/153814-earthj2.svg).
- **Малая негравитационная поправка.** У 613569 существенным оказался
  доступный номинальный A2. Сохраняем объяснение того, почему слабое
  ускорение может накопить заметную ошибку.
  [Данные и результаты обоих случаев](DEVELOPMENT30_OUTLIER_AUDIT_REPORT.md).
- **Где находится Апофис и с чем встречается.** Солнечная орбита, пролёт
  Земли и геометрия относительно Луны.
  [Сохранённая интерактивная карта](figures/physics_diagnostics/apophis-trajectory.html),
  [проверка Луны и Венеры](APOPHIS_MOON_VENUS_REPORT.md).
- **Что меняли следующие проверки.** Сохраняем J2/NG-панель, проверку
  начального состояния, согласования эфемерид и численного метода.
  [Историческая панель Апофиса](figures/physics_diagnostics/apophis-j2-ng.svg),
  [чувствительность к начальным данным](APOPHIS_INITIAL_SENSITIVITY_REPORT.md),
  [финальный аудит Апофиса](APOPHIS_ENCOUNTER_CLOSURE_REPORT.md).

Старые панели показывают результаты своих этапов. Их подписи должны
сохранять дату, модель и окно: раннее расхождение около 10–13 km и итоговые
2.552 km у Апофиса относятся к разным расчётам. Адресное улучшение после
разбора ошибки не заменяет результат независимой проверки селектора.

Для этой истории уже есть SVG и HTML. Новые GIF из итоговой галереи можно
добавить рядом как иллюстрации движения. Отдельных GIF «до/после Earth J2»
для 153814 и «до/после A2» для 613569 в текущей галерее нет; это возможное
расширение оформления, если захочется именно анимировать эти две проверки.

## 3. Форма Апофиса — отдельная визуальная карточка

Сохраняем именно понравившуюся реконструкцию с тремя проекциями:

![Апофис: предварительная PDS Model B, три проекции в общем масштабе](figures/physics_diagnostics/apophis-pds-shape.svg)

Рядом — короткое объяснение: неправильная форма, контактные доли и двойная
система с отдельным спутником описывают разные свойства. В
[исследовании формы](APOPHIS_SHAPE_WEAK_FORCE_REPORT.md) уже есть сравнение
с Eros, Apollo, Phaethon, Itokawa и Didymos, а также оценки влияния формы.

У изображения сохраняем источник PDS / Brozović et al., статус preliminary
Model B, масштаб и подпись «реконструкция». В сценах движения такая форма
может служить иллюстрацией тела. Рассчитанная ориентация и вращение при
пролёте требуют отдельной модели; текущая галерея использует маркеры.

В оформлении каждой пары сохраняем:

- одну дату для положения прогнозного и эталонного тела;
- постепенно растущие следы обеих траекторий;
- подписи объекта, модели, горизонта, единиц и настоящей 3D-ошибки;
- общий масштаб осей и явное указание увеличения **только разности**;
- пояснение, что Horizons — вычисленная номинальная эфемерида, используемая
  как эталон сравнения.

Обзор показывает настоящее пространственное расстояние между линиями.
На усиленном крупном плане видимая оранжевая линия иллюстрирует остаток;
его нельзя воспринимать как физически огромный уход астероида в сторону.
У двух крупных планов 229215 разные коэффициенты увеличения, поэтому
точность сравнивается по метрам, а не по расстоянию между линиями в пикселях.

## 5. Предложение по главной странице

Это предлагаемая компоновка, а не дополнительное пожелание из обсуждения:

1. **Короткая идея проекта.** «Как выбрать достаточно точную физическую
   модель движения астероида и не считать все возмущения каждый раз?»
2. **Одна заметная GIF.** Годовой 2001 AV43 с прогнозом и Horizons;
   следом — его отдельный крупный план расхождения.
3. **Несколько главных чисел.** 100 новых тел, 500 вложенных окон,
   500/500 при 1 km у обоих v4; 30.10% экономии времени физического правила
   на заранее выбранных 24 телах. ML уменьшил максимум ошибки, но не дал
   дополнительных успешных окон или выигрыша времени относительно правила.
4. **«Как физика помогала искать ошибку».** Превью Earth J2 и формы Апофиса,
   несколько предложений и ссылка на полный рассказ.
5. **Галерея разных случаев.** Ссылка на все 19 GIF, включая ограничения.
6. **Как устроено и как проверить.** Ссылки на
   [API селектора](SELECTOR_V4_USAGE.md), [итоговый отчёт](SELECTOR_CONFIRMATION100_REPORT.md)
   и [данные](DATA_GUIDE.md).
7. **Что остаётся открытым.** Коротко: Апофис, строгие 100 m и надёжность
   предупреждений; подробности — в [разборе ограничений](SELECTOR_CONFIRMATION100_DIAGNOSTICS.md).

Основной README можно позже сократить до этой последовательности,
оставив всю историю и таблицы в связанных документах. Для самих страниц
репозитория готовые GIF/SVG служат превью; сохранённый HTML остаётся
дополнительным интерактивным файлом для открытия в браузере.
