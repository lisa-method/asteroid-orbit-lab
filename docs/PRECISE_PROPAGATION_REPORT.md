# Апофис: исправление накопления округлений

**Уточнение 2026-09-09.** Восемь сохранённых Apophis headers объявляют
`EOBL_MOD = 2x0 (J2 only)`. Описанный ниже эффект J3/J4 численно реален,
но его нельзя считать восстановлением пропущенных гармоник этого teacher.
Уменьшение остатка могло компенсировать другое отличие модели.
[Отдельная проверка соглашений и солнечного J2](APOPHIS_GRAVITY_CONVENTIONS_REPORT.md).
Числа и frozen артефакты этого отчёта сохранены.

Дата: 2026-09-08. Два законченных, отдельно замороженных численных
эксперимента: 24 RK4/DP сравнения и 12 дополнительных compensated DP.
[Первый контракт](PRECISE_PROPAGATION_CONTRACT.md),
[контракт продолжения](PRECISE_DP_CONTRACT.md).

## Результат

Километровая нестабильность старого RK4 устранена в новой версии численной
схемы. При неизменной физике compensated RK4 сходится до сантиметров при
уменьшении шага. Межметодное расхождение с compensated DP составляет
1.24–1.27 m; заранее установленный критерий ≤1 m **не выполнен**.
Это существенное улучшение, но не строгая оценка глобальной ошибки.

Поправка Earth J3+J4 подтверждается двумя алгоритмами: её векторный эффект
на годовую траекторию около 1.9235 km, разница эффектов между алгоритмами
около 2.12 cm для старого initial и 1.57 mm для нового. При этом остаток
относительно согласованного Horizons teacher остаётся примерно 8.5 km.
Он не исчезает после исправления обнаруженной численной нестабильности;
его физическая/референсная причина по-прежнему не установлена.

## Что изменилось

Старый RK4 вычислял приращение состояния с выбранным h, а время сохранял
как округлённое t+h. Фактическая разность соседних времён может отличаться
от h. Дополнительно обычное сложение многих малых приращений с координатой
масштаба AU теряло младшие разряды. Близкий пролёт усиливает последствия
очень малых различий до пролёта.

Новый `precise_rk4.py` сначала выбирает правую границу шага, затем использует
точно h=right−left для стадий и состояния. Режим `compensated=True` сохраняет
потерянные разряды с помощью компенсации Кэхэна для шести компонент.
Алгоритм выбора размера шага, force callback и начальные состояния прежние.

У согласования только времени недостаточная устойчивость. Для старого
initial и baseline годовые matched errors на scales 0.5/0.25/0.125:

| Численная схема | 0.5, km | 0.25, km | 0.125, km |
|---|---:|---:|---:|
| Прежний RK4, точное воспроизведение | 10.613735 | 10.175775 | 11.454025 |
| Согласование h с временем | 10.411634 | 10.418355 | 10.429225 |
| Согласование + компенсация | 10.416348 | 10.415430 | 10.415386 |

Ещё меньший compensated scale 0.0625 даёт 10.415395 km. Нужен именно
парный векторный контроль, а не только близость этих скалярных ошибок:
различия соседних compensated forecasts 0.9173 m, 4.471 cm и 0.980 cm.
Для остальных трёх initial/force ветвей scales 0.25/0.125 различаются
на 3.590–4.139 cm.

Дополнительный `precise_dopri.py` применяет согласование времени,
компенсацию accepted-state и `math.fsum` для взвешенных сумм стадий и
embedded error. Отклонённый шаг не меняет компенсацию; FSAL производная
вычисляется в фактическом принятом состоянии. Это совместное изменение
трёх численных деталей, а не оценка вклада каждой по отдельности.

## Межметодная проверка и физический эффект

Сравниваются 797 одинаковых узлов, включая прежнюю сетку пролёта. Старый
initial оценивается по старому daily teacher; новый annual-hourly initial —
по согласованному annual-daily teacher. Ряды не смешиваются.

| Initial / силы | Fine compensated RK4, matched error km | Compensated DP ultra, matched error km | Max разница решений, m |
|---|---:|---:|---:|
| Старый / J2 baseline | 10.415386 | 10.416652 | 1.267 |
| Старый / J2+J3+J4 | 8.492064 | 8.493310 | 1.246 |
| Annual / J2 baseline | 10.462653 | 10.463895 | 1.242 |
| Annual / J2+J3+J4 | 8.539332 | 8.540576 | 1.244 |

В таблице RK4 scale=0.125; дополнительный старый baseline scale=0.0625
отличается от DP ultra на 1.257 m. DP extreme/ultra дают 0.139–0.159 m
разницы. Малое изменение настроек одного алгоритма само по себе не
доказывает такую же абсолютную точность; остаток между алгоритмами больше.

Для J3/J4 сравниваются непосредственно векторы
`(r_J3J4 − r_baseline)_DP − (r_J3J4 − r_baseline)_RK4`.
Эффект DP ultra: 1.923541/1.923522 km; межметодное различие этих векторов
0.021197/0.001573 m, старый/новый initial соответственно. Общий численный
сдвиг сильно сокращается в парном сравнении, поэтому уверенность в этом
конкретном force effect выше, чем в метровой точности каждой траектории.
Это не общая гарантия для произвольной новой слабой силы.

Полная shape/spin/thermal эволюция в этих опытах отсутствует. Прежние
три fixed-attitude shape проверки не пересчитываются как новые результаты.
Номинальные NG коэффициенты сохранены; дополнительный тепловой эффект
поверх уже используемого A2 не вводился.

## Проверки и воспроизведение

Первый offline verifier проверил 24 immutable checkpoints, 84 парных
сравнения, 154656 скалярных ошибок позиции/скорости и 1155594 native
endpoints. Три старых RK4 и восемь прежних DP traces воспроизведены точно.
Второй verifier проверил 12 checkpoints, 77328 скалярных ошибок и 27412
native endpoints. Оба сверяют все восемь reference tables, source/input
hashes и runtime; 137 raw файлов в 13 manifests проходят SHA/size/Git
exclusion checks. Эти числа включают повторные сравнения одних и тех же
физических узлов с разными таблицами и не являются числом независимых опытов.

Python 3.14.7, standard library only. Из корня проекта:

```bash
env UV_CACHE_DIR=/private/tmp/astrophysics-ml-uv-cache UV_OFFLINE=1 UV_PYTHON_DOWNLOADS=never uv run --no-project --python-preference only-system --python 3.14.7 python -B src/verify_precise_propagation.py
env UV_CACHE_DIR=/private/tmp/astrophysics-ml-uv-cache UV_OFFLINE=1 UV_PYTHON_DOWNLOADS=never uv run --no-project --python-preference only-system --python 3.14.7 python -B src/verify_precise_dp.py
```

Генераторы `src/run_precise_propagation.py` и `src/run_precise_dp.py` на
завершённом наборе читают checkpoints, не запускают propagation заново и не
переписывают результаты. Для новых настроек нужна отдельная версия.

Артефакты: `outputs/precise_propagation/` и `outputs/precise_dp/` — локальные,
исключены из Git. Matrix SHA-256 соответственно:

Все прежние propagators, matrices и selector scores сохранены. Численное
исправление не превращает post-hoc результаты в новый holdout score.

причина примерно 8.5 km Apophis teacher mismatch.
